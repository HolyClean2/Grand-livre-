Méthode boule de neige — minimums partout + un extra fixe et modeste
Pourquoi un extra modeste plutôt que le maximum ?

Un montant fixe et soutenable, payé chaque paie sans exception, bat un montant élevé abandonné après trois paies. La constance compte plus que l'intensité.

CELI — priorité future

À activer une fois Easy Financière (et autres dettes à intérêt élevé) éliminées
Pourquoi attendre ?

Emprunter pour investir ne vaut pas le coup tant qu'une dette à taux élevé (34.70%) est active — aucun rendement de marché raisonnable ne bat ce taux de façon fiable.

Principes directeurs pour plus tard

CELI en priorité (croissance à l'abri de l'impôt), fonds indiciels diversifiés, cotisations automatiques par paie (dollar-cost averaging) plutôt que des essais de timing de marché.

Configuration (une seule fois, ~10 min)

1. Crée un nouveau Google Sheet (sheets.new).
2. Menu Extensions → Apps Script.
3. Efface le contenu et colle le code fourni dans le README (section "Google Sheet").
4. Clique Déployer → Nouveau déploiement → type "Application Web".
5. Exécuter en tant que : Moi. Accès : Tout le monde.
6. Clique Déployer, autorise les permissions demandées.
7. Copie l'URL qui se termine par /exec et colle-la ci-dessous.
